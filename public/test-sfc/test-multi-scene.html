🎬 多场景管理器 - 测试页面

📋 说明

此页面用于测试多场景管理器的分层 Near/Far 功能。

请确保已在含有 DualCanvasViewer 的页面中打开控制台执行测试脚本。

🚀 快速测试

在含有 DualCanvasViewer 的页面控制台中，执行以下任一方式：

方式1：使用一键测试脚本（推荐）

1. 确保以下文件在服务器上可访问：

  • multi-scene-manager.js
  • multi-scene-debug.js
  • test-multi-scene.js

2. 在控制台执行：

load('test-multi-scene.js')

方式2：手动加载脚本

在控制台依次执行：

// 加载核心管理器
const script = document.createElement('script');
script.src = 'multi-scene-manager.js';
document.head.appendChild(script);

// 等待加载后初始化
setTimeout(() => {
  const manager = new MultiSceneManager(window.__dualCanvasViewer);
  manager.initialize();
  window.__multiSceneManager = manager;
}, 1000);

方式3：直接在控制台粘贴代码

打开 multi-scene-manager.js，复制全部内容到控制台执行

🔧 测试命令

初始化完成后，可以使用以下命令测试：

查看调试信息

// 查看当前状态
const info = window.__multiSceneManager.getDebugInfo();
console.table(info.scenes);
console.table(info.cameras);

// 显示调试面板（需加载 multi-scene-debug.js）
showMultiSceneDebug();

测试相机同步

// 手动触发相机同步
window.__multiSceneManager.syncCameras();

// 查看相机位置
console.log('大坐标相机:', window.__multiSceneManager.cameras.layer1Large.position);
console.log('小坐标相机:', window.__multiSceneManager.cameras.layer1Small.position);

测试渲染

// 手动触发渲染
window.__multiSceneManager.renderLayer1();
window.__multiSceneManager.renderLayer2();

🐛 故障排查

问题：DualCanvasViewer 未找到

原因：页面未正确加载 DualCanvasViewer

解决：确保在正确的页面中执行脚本

问题：脚本加载失败

原因：文件路径不正确或服务器未启动

解决：检查文件路径，确保通过 HTTP 服务器访问

问题：模型显示位置不正确

原因：参考点选择不当

解决：

// 查看当前参考点
const info = window.__multiSceneManager.getDebugInfo();
console.log('参考点:', info.referencePoints);

// 重新分类模型
window.__multiSceneManager.classifyAndMoveModels();

问题：深度排序仍然错误

原因：near/far 范围设置不当

解决：

// 调整小场景的 near/far
const manager = window.__multiSceneManager;
manager.cameras.layer1Small.near = 10;
manager.cameras.layer1Small.far = 2000;
manager.cameras.layer1Small.updateProjectionMatrix();
