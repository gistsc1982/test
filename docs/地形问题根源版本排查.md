 vite.config.ts 里 base: "/yjjg-dp/"，URL 前缀没问题。但 layer.json 里 tilingScheme: "geographic" — Cesium 期望的是 "geodetic"！这可能导致
  CesiumTerrainProvider 用错坐标系。

LocalTerrainProvider 是为 Cesium 1.97 写的，和 1.132 的渲染管线不兼容。具体原因：
   
  1. HeightmapTerrainData 构造函数 API 变了——LocalTerrainProvider 传入的 structure 对象格式在 1.132 中语义不同，导致 Cesium
  内部计算出错
  2. GeographicTilingScheme 行为变了——1.132 中 terrain tile 坐标系处理方式改动，LocalTerrainProvider 返回的瓦片和 globe
  预期位置错位
  3. 子瓦片细化链断了——childTileMask 计算逻辑在 1.132 中触发无限细化，崩溃前渲染出全零占位瓦片（平面），把覆盖物遮挡住
  4. mousedown 闪现——Cesium 拾取 pass 临时跳过 terrain 深度测试，覆盖物短暂可见；mouseup 恢复渲染后又被遮挡
