 通用化 Cesium 实体闪烁工具方案

 背景

 项目中存在两套闪烁实现：

 ┌──────────┬─────────────────────────────────────────────┬────────────────────────────────────────────────┐
 │          │         GeoJsonLayerManager（可靠）         │      SpacialQueryManager（历经多次试错）       │
 ├──────────┼─────────────────────────────────────────────┼────────────────────────────────────────────────┤
 │ 闪烁方式 │ 每 500ms 直接切换 entity.polygon.material   │ setInterval + SDK FlashEntityByColor           │
 ├──────────┼─────────────────────────────────────────────┼────────────────────────────────────────────────┤
 │ SDK 依赖 │ 无（持续模式绕过 SDK）                      │ 每次新建 SceneEffect 实例                      │
 ├──────────┼─────────────────────────────────────────────┼────────────────────────────────────────────────┤
 │ 实体来源 │ viewer 中已渲染的现有实体                   │ 每次闪烁单独创建新 GeoJsonDataSource           │
 ├──────────┼─────────────────────────────────────────────┼────────────────────────────────────────────────┤
 │ 颜色处理 │ getValue(currentTime) 提取 Property + clone │ 无预处理，受 SDK 的 Property vs Color bug 影响 │
 ├──────────┼─────────────────────────────────────────────┼────────────────────────────────────────────────┤
 │ 状态恢复 │ 保存原始颜色，停止时恢复                    │ 移除临时 DataSource，toggle 绿色高亮 show/hide │
 └──────────┴─────────────────────────────────────────────┴────────────────────────────────────────────────┘

 核心发现：直接操作 Cesium 实体属性（entity.polygon.material = newColor）是唯一可靠的持续闪烁方式。SDK 的
 FlashEntityByColor 存在 Property/Color 类型不匹配的 bug（需要 monkey-patch），且每次调用创建新 SceneEffect
 实例，不适合持续循环。

 新工具：src/utils/EntityBlinkManager.js

 设计决策

 - 可实例化类（非单例）—— 每个消费者（GeoJsonLayerManager / SpacialQueryManager /
 未来的其他组件）创建自己的实例
 - 零项目依赖，仅依赖 Cesium.Viewer
 - 内部用 Map<blinkId, BlinkSession> 管理多个闪烁会话
 - 不依赖 SGKJ_SDK

 API

 ┌──────────────────────────────────┬─────────────────────────────────────┐
 │               方法               │                说明                 │
 ├──────────────────────────────────┼─────────────────────────────────────┤
 │ start(entity, options) → blinkId │ 开始闪烁，返回会话 ID               │
 ├──────────────────────────────────┼─────────────────────────────────────┤
 │ stop(blinkId) → boolean          │ 停止指定会话                        │
 ├──────────────────────────────────┼─────────────────────────────────────┤
 │ stopByEntity(entity) → number    │ 停止该实体的所有会话                │
 ├──────────────────────────────────┼─────────────────────────────────────┤
 │ stopAll()                        │ 清理全部                            │
 ├──────────────────────────────────┼─────────────────────────────────────┤
 │ toggle(entity, options)          │ 开/关切换                           │
 ├──────────────────────────────────┼─────────────────────────────────────┤
 │ isBlinking(entity) → boolean     │ 查询状态                            │
 ├──────────────────────────────────┼─────────────────────────────────────┤
 │ destroy()                        │ 完整清理（组件 beforeUnmount 调用） │
 └──────────────────────────────────┴─────────────────────────────────────┘

 核心实现：_tick(session) — 500ms setInterval

 直接切换实体属性，完全绕过 SDK：

 ┌───────────┬───────────────────────────────────────────────────┬─────────────────────────────────────────┐
 │  geoType  │                      高亮 ON                      │          高亮 OFF（恢复原始）           │
 ├───────────┼───────────────────────────────────────────────────┼─────────────────────────────────────────┤
 │ polygon   │ material = 高亮色 α0.45, outlineColor = 高亮色,   │ material = 原始, outlineColor = 原始,   │
 │           │ outlineWidth = 3                                  │ width = 原始                            │
 ├───────────┼───────────────────────────────────────────────────┼─────────────────────────────────────────┤
 │ polyline  │ material = 高亮色, width = 5                      │ material = 原始, width = 原始           │
 ├───────────┼───────────────────────────────────────────────────┼─────────────────────────────────────────┤
 │ point     │ color = 高亮色, pixelSize = 18                    │ color = 原始, pixelSize = 原始          │
 ├───────────┼───────────────────────────────────────────────────┼─────────────────────────────────────────┤
 │ billboard │ color = 高亮色, scale = 1.3                       │ color = 原始, scale = 原始              │
 ├───────────┼───────────────────────────────────────────────────┼─────────────────────────────────────────┤
 │ model     │ silhouetteColor = 高亮色, silhouetteSize = 3      │ 恢复原始                                │
 └───────────┴───────────────────────────────────────────────────┴─────────────────────────────────────────┘

 原始状态保存

 处理两种 Cesium 颜色类型：
 - ConstantProperty(Color)：prop.getValue(currentTime) 提取原始 Color → clone
 - 原始 Cesium.Color：直接 clone

 边界情况

 - 实体中途销毁：每 tick 检查 entity.isDestroyed，自动停止
 - Viewer 销毁：destroy() 清理所有会话
 - 多个并发闪烁：每个 blinkId 独立，互不干扰
 - 实体尚未渲染：Entity API 是声明式的，直接设属性即可，不依赖渲染状态

 集成方案（3 个文件）

 1. 新建：src/utils/EntityBlinkManager.js（~200 行）

 纯 Cesium 工具类。包含 geoType 自动检测、原始状态保存/恢复、_tick 切换循环。

 2. 修改：src/utils/EntitySelectionManager.js

 _applyContinuousHighlight（行 1777-1855）和 _stopContinuousFlash（行 1860-1903）改为委托给
 EntityBlinkManager：

 // 之前 ~120 行内联闪烁逻辑
 // 之后 ~30 行委托
 _applyContinuousHighlight: function(entity, geoType, viewer, Cesium) {
   if (!this._blinkManager) this._blinkManager = new EntityBlinkManager(viewer);
   this._continuousBlinkId = this._blinkManager.start(entity, {
     color: Cesium.Color.fromCssColorString('#FFD600'),
     interval: 500
   });
 },
 _stopContinuousFlash: function() {
   if (this._blinkManager) this._blinkManager.stop(this._continuousBlinkId);
 }

 移除旧字段：_continuousFlashInterval/Entity/OrigColor/GeoType/Viewer。

 3. 修改：src/components/functions/spacialQueryManager/SpacialQueryManager.vue

 关键变化：不再为闪烁创建独立的 GeoJsonDataSource，而是直接闪烁已有绿色高亮实体（从
 _highlightEntities[index].entities.values[0] 获取）。

 - 移除：_flashLoop、_detectEntityGeoType、_blinkInterval、_blinkTimeout、_blinkDataSource、_blinkEntities
 - 新增：_blinkManager（EntityBlinkManager 实例）、_blinkId
 - _startBlink 改写：找到绿色高亮中对应的实体 → 直接调用 _blinkManager.start(entity, { color: purple })
 - _stopBlink 简化：只调用 _blinkManager.stop(_blinkId)，不再需要 show/hide 绿色高亮
 - clearResults 简化：移除闪烁保护条件，blinkManager 自动处理
 - 新增 _findEntityForFeature(index)：从 _highlightEntities[index] 提取实体引用

 净效果：~100 行删除，~40 行新增，彻底移除 SDK FlashEntityByColor 依赖。

 验证

 1. GeoJsonLayerManager：点击地图上 geojson-polygon-1 的要素 → 黄色持续闪烁 → 点另一个 → 旧停新起 → 点空白 →
 停止。应与当前行为完全一致。
 2. SpacialQueryManager：执行 WFS 查询 → 点击结果行 → 对应绿色高亮实体变紫色闪烁 → 再点同一行 → 停止并恢复绿色
 → 点不同行 → 切换闪烁目标 → 点"定位"按钮 → 相机飞至要素。
 3. 相机交互：闪烁中缩放/平移 → 闪烁不受影响（EntityBlinkManager 独立于相机 handler）。
 4. 边界：闪烁中关闭面板 → beforeUnmount 调用 destroy() 清理。闪烁中执行新查询 → clearHighlights 销毁实体 →
 blink auto-stop 无报错。
