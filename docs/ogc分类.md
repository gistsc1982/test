OGC 服务分类
     
  🎨 有样式的（服务端渲染图像）

  ┌─────────────────┬────────────────────────────────┬──────────────────────────────────────┐
  │      服务       │            样式机制            │            GetStyles 来源            │
  ├─────────────────┼────────────────────────────────┼──────────────────────────────────────┤
  │ WMS             │ SLD（Styled Layer Descriptor） │ ✅ GetStyles / GetLegendGraphic      │
  ├─────────────────┼────────────────────────────────┼──────────────────────────────────────┤
  │ WMTS            │ 预定义 Style ID                │ ✅ GetCapabilities 中列出 Style 元素 │
  ├─────────────────┼────────────────────────────────┼──────────────────────────────────────┤
  │ OGC API - Maps  │ Style 对象                     │ ✅ /styles 端点                      │
  ├─────────────────┼────────────────────────────────┼──────────────────────────────────────┤
  │ OGC API - Tiles │ TileMatrixSet + Style          │ ✅ 关联的 Map 服务                   │
  └─────────────────┴────────────────────────────────┴──────────────────────────────────────┘

  📊 无样式的（返回原始数据，客户端自定样式）

  ┌───────────────────┬──────────────────────────────────┬───────────────────────────────────────────────────────────────┐
  │       服务        │             返回内容             │                         为什么无样式                          │
  ├───────────────────┼──────────────────────────────────┼───────────────────────────────────────────────────────────────┤
  │ WFS               │ GML / GeoJSON 要素数据           │ 纯数据，WFS 1.1 有实验性 GetStyles 但 2.0                     │
  │                   │                                  │ 已移除，几乎没有服务端实现                                    │
  ├───────────────────┼──────────────────────────────────┼───────────────────────────────────────────────────────────────┤
  │ WCS               │ GeoTIFF / NetCDF 栅格数据        │ 返回原始栅格值，配色（如 NDVI 假彩色）是客户端的事            │
  ├───────────────────┼──────────────────────────────────┼───────────────────────────────────────────────────────────────┤
  │ WPS               │ 任意计算结果（JSON/XML/GeoTIFF） │ 返回的是处理结果，不是地图                                    │
  ├───────────────────┼──────────────────────────────────┼───────────────────────────────────────────────────────────────┤
  │ CSW               │ ISO 19115 元数据记录             │ 搜索引擎，返回 XML 元数据                                     │
  ├───────────────────┼──────────────────────────────────┼───────────────────────────────────────────────────────────────┤
  │ SOS               │ 传感器观测数据                   │ 纯时序数据                                                    │
  ├───────────────────┼──────────────────────────────────┼───────────────────────────────────────────────────────────────┤
  │ OGC API -         │ GeoJSON 要素                     │ 等价于 WFS 3.0，纯数据                                        │
  │ Features          │                                  │                                                               │
  ├───────────────────┼──────────────────────────────────┼───────────────────────────────────────────────────────────────┤
  │ OGC API -         │ 栅格/ Coverage 数据              │ 等价于 WCS 3.0                                                │
  │ Coverages         │                                  │                                                               │
  └───────────────────┴──────────────────────────────────┴───────────────────────────────────────────────────────────────┘

  🗺️  地理编码服务

  地理编码（正向/反向）不是 OGC 标准。OGC 曾有过 OpenLS（Location
  Services）包含地理编码，但早已废弃。当前主流实现（天地图、高德、Google）都是各家的 REST API，返回 JSON
  坐标，不存在样式概念。
