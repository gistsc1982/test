  当前最终方案（Cesium 1.81 兼容的 ja-yjjg-dp 混合方案）

  getTileDataAvailable     → bounds 检查（1.81 必需，告诉 Cesium 无数据区域回落椭球面）
  requestTileGeometry      → ja-yjjg-dp 风格：
                              • 前置 bounds 检查 → undefined（双重保险）
                              • 像素越界 → 置 0（不钳制到边界）
                              • childTileMask = 15（始终允许细化）
                              • 同步返回（不包装 Promise）
  getLevelMaximumGeometricError → return 0（委托 Cesium 默认 LOD）
  _minLevel                → 0（不使用占位 tile）
