GeoJsonLayerManager 性能 & 外观优化方案

 Context

 当前 GeoJsonLayerManager.loadLayer() 在加载 GeoJSON 后做了两件多余的事：
 1. 用 canvas 绘制 emoji 图标覆盖 Cesium 原生标记 — PinBuilder 已经用 markerColor
 生成了漂亮的渐变圆点，随后被 canvas emoji 覆盖
 2. 逐实体迭代设置 clampToGround — GeoJsonDataSource.load() 的 options 参数已经支持
 clampToGround，不必事后逐实体设

 这导致 GeoJsonLayerManager 比 LayerTreeManager 加载慢且标记外观不如原生 PinBuilder 渐变圆点。

 改动文件

 src/components/functions/GeoJsonLayerManager/GeoJsonLayerManager.vue

 1. 删除 canvas emoji + 逐实体迭代（第 182-224 行）

 删除整个 entities.forEach((entity, idx) => { ... }) 块。

 理由：
 - GeoJsonDataSource.load(geoJsonData, options) 传入的 markerColor + markerSize 已让 Cesium 通过
 PinBuilder.fromColor() 生成渐变圆点（和 LayerTreeManager 默认效果一致）
 - clampToGround 已在 options 中传入，Cesium 内部应用到所有实体
 - 不需要 canvas 创建、不需要逐实体 billboard 替换

 2. options 中增加 markerSymbol 字段

 当用户设置 markerIcon 为单个 ASCII 字符（如 A、★、1）时，传 markerSymbol 让 PinBuilder
 原生渲染；其他情况传 undefined → Cesium 使用渐变圆点。

 const markerIcon = layer.markerIcon;
 const markerSymbol = (markerIcon && markerIcon.length === 1 && markerIcon !== '📍')
     ? markerIcon
     : undefined;

 const options = {
     clampToGround,
     fill: fillColor,
     markerColor: Cesium.Color.fromCssColorString(layer.markerColor || '#4169E1'),
     markerSize: layer.markerSize || 48,
     stroke: Cesium.Color.fromCssColorString(layer.strokeColor || '#FF0000'),
     strokeWidth: effectiveStrokeWidth,
     markerSymbol  // ← 新增
 };

 - undefined → PinBuilder.fromColor() 渐变圆点（性能最好、外观最佳）
 - 单字符 → PinBuilder.fromText() 原生文字标记（仍比 canvas 快）

 src/components/functions/GeoJsonLayerManager/GeoJsonLayerManager.config.json

 3. 默认值调整（可选，仅影响新建图层）

 将 markerIcon 默认值从 "📍" 改为 ""（空字符串），新创建的图层默认使用渐变圆点：

 { "key": "markerIcon", "default": "", ... }

 已存在的图层不受影响，可手动编辑清除 markerIcon 字段切换为渐变圆点。
