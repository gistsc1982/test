 WebODM / Metashape / Pix4D 与 Dual 双层 Three.js 组件集成分析

 Context

 当前项目（ja-yjjg-dp / test）的核心可视化架构为 DualCanvasViewer（dual 双层组件）：

 Container
   ├── Cesium 地球（底图 + 地形 + 3D Tiles）
   └── DualCanvasViewer（z-index 叠加层）
         ├── Layer 1: 原始模型层（Three.js scene1, GLB/PLY/DRC/高斯泼溅）
         └── Layer 2: BIM 模型层 （Three.js scene2, GLB）

 已支持的 Three.js 数据格式：GLB/glTF（通过 GLTFLoader + DRACOLoader）、PLY（PLYLoader）、DRC（DracoDecoderModule）、3D
 高斯泼溅（通过 DRC 检测高斯属性）

 已支持的 Cesium 数据格式：3D Tiles（B3DM，通过 Cesium3DTileset.fromUrl()）、quantized-mesh-1.0 地形瓦片、heightmap-1.0 地形、GeoTIFF
 DEM（通过 GeoTiffTerrainProvider）

 已有转换管线：B3DM → GLB（PCA 自动贴地对齐 + ECEF 坐标保留 + 地理位置元数据嵌入，详见 docs/B3DM-ECEF-TO-GLB-GUIDE.md）

 推荐集成管线（三款软件中最优）

 Metashape → File → Export Model → glTF
   设置：
     - 格式：GLB（单文件，含纹理）
     - Draco 压缩：开启
     - Texture atlas：合并为单张（2K-4K）
     - 减面：50K-300K 面（Web 优化）
     - 坐标：Tools → Transform → Translate 居中到原点附近
     - 取消 "Export in world coordinates"（用于 Web/游戏引擎）
   → DualCanvasViewer.loadThreeModel() 加载到 Three.js 层
   → 如需地理定位：保留并导入外部坐标元数据

 大场景：
 Metashape → Build Tiled Model → Export Cesium 3D Tiles 1.1 (.3tz)
   → Cesium 层加载
   → 或逐个 B3DM 转换：convert-b3dm-ECEF-to-glb.js

 地形：
 Metashape → Export DEM → GeoTIFF
   → GeoTiffTerrainProvider.fromUrl() 或预切片 .terrain 瓦片

 优势：GLB 导出减少文件体积高达 80%（相比 OBJ/FBX + 外部纹理）
